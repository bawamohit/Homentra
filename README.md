# Homentra Real Estate Website

Welcome to the Homentra project! This is a personal real estate website designed to showcase properties and provide potential clients with information about our services.

## Project Structure

The project is organized as follows:

```
homentra
├── src
│   ├── index.html        # Main landing page
│   ├── about.html        # About page detailing services and mission
│   ├── contact.html      # Contact page with a form for inquiries
│   ├── assets
│   │   ├── css
│   │   │   └── custom.css # Custom styles for the website
│   │   ├── js
│   │   │   └── main.js    # JavaScript for interactive functionality
│   │   └── images         # Directory for images used in the website
├── package.json           # npm configuration file
├── README.md              # Project documentation
└── .gitignore             # Files and directories to be ignored by Git
```

## Features

- **Responsive Design**: The website uses Bootstrap for a mobile-friendly layout.
- **About Section**: Provides information about Homentra and the services offered.
- **Contact Form**: Allows potential clients to reach out with inquiries.
- **Custom Styles**: Additional styling can be found in `custom.css`.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd homentra
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in your web browser to view the website.
